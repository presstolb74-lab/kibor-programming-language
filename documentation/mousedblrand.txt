НАЗВАНИЕ: mousedblrand
ИСТОЧНИК: http://kibor-bot.com/forum/topic.php?forum=1&topic=45

В настройки добавил возможность указать свою паузу в функциях mouse, key, mousedbl, sendmousedbl, sendmouse, sendkey.
Можно отредактировать паузу которая между нажатием и отпусканием кнопки и двойным кликом мышки.
Добавил функции рандомизации этих пауз программно.
keymouserand - рандомизирует паузу между нажатием и отпусканием кнопок в mouse, key, sendmouse, sendkey.
mousedblrand- рандомизирует паузу между двойным кликом мышки в  mousedbl, sendmousedbl.
Синтаксис
keymouserand(50);// увеличивает паузу между нажатием и отпусканием на 0 - 50 мсек.
mousedblrand(120);// увеличивает паузу двойным кликом мышки на 0 - 120 мсек.
Принимается только положительное число. Для включения рандома достаточно вызвать эти функции в начале скрипта один раз. После вызова каждая пауза будет рандомизироваться отдельно.
Для отключения рандома надо вызвать эти функции с нулем
Цитата:
keymouserand(0);
mousedblrand(0);
