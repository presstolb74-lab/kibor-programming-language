antianticlicker
Позволяет включить и выключить антиантикликер программно.
Пригодится в собранных exe..
antianticlicker (1);//включает публичный
antianticlicker (0);//выключает публичный
antianticlicker(1, "x32");//Включает приватный антиантикликер который справляется на данный момент с любой защитой
antianticlicker(0, "x32");//выключает приватный
Что бы так и дальше было - Подробнее о этом антиантикликере. Ограничение нелицензированных версий и получение лицензии
Настройка опций включения антиантикликера. Описание функции options ниже.
CODE:
options ("antianticlicker", 2, 1, 0, 0, 5, 0, 0);
antianticlicker (1);
key('D');
pause(1000);
key(SPACE);
pause(1000);
key('D');
Пример как это можно сделать в созданном окне
CODE:
CREATE_INTERFACE
{
DIALOG "Название окна" 237 180 //РазмерX РазмерY
BUTTONSCRIPT "Запустить" 125 121 100 25 //ПозицияX ПозицияY РазмерX РазмерY
//Добавление контролов управления ......
CHECK_0 0 /*Выключена*/ "Включить антиантикликер" 10 10 155 18 //ПозицияX ПозицияY РазмерX РазмерY
}
antianticlicker( getcontrol(CHECK_0));

Добавил возможность управления настройками в собранном EXE
Пример установки настроек в антиантикликере:
options ("antianticlicker", int, int, int, int, int, int, int );
Параметры
Первый - указать что настраиваем
Второй - тип мыши. 2 - 2 кнопки или тачпад, 3 - 3 кнопки.
Третий - включить эмуляцию клавы. (1 вкл, 0 выкл)
Четвертый - включить эмуляции мыши клик. (1 вкл, 0 выкл)
Пятый - включить эмуляции мышь движение. (1 вкл, 0 выкл)
Шестой - скорость движения (1 - 10 )
Седьмой - 0 не проводить тест антиантикликера, 1 проводить
Восьмой  - 1 выводить сообщения антиантикликера, 0 не выводить
options ("antianticlicker", 2, 1, 1, 1, 5, 1, 1);
Важно! Выставлять опции перед включением антиантикликера.
Если зависает при включение АнтиАнтиКликера и девайсы ps/2 есть - отключить тестирование мыши и клавиатуры в настройках АнтиАнтиКликера..
-----===========--------------
Так же в функции options  можно настроить программно параметры идущие в вкладке настроек кибора (паузы).
options ( "pause" , 35, 85, 1);
установит паузу 35 мсек между нажатием и отпусканием кнопки мыши и клавы в функциях key   и   mouse.
и паузу 85 мсек между двойными кликами  ( mousedbl )..
Так же третий параметр включит паузу и дрожь мышь в конечной координате передвижения или клика. Если поставить 0 - отключит.
-----===========--------------
В  options  можно изменить горячую клавишу остановки скрипта.
То есть саму букву.
options ("stop","C");
Будет останавливать скрипт по КОНТР ШИФТ C
Внимание! Во втором параметре должна быть англ. буква большого регистра.
-----===========--------------
Указав первым параметром "close" можно отключать обязательное подтверждение при попытке закрыть программу при выполнение скрипта.
При работе скрипт не с EXE, а Кибор данная опция имеет приоритет галки установленной в Настройки - Общие.
Данная настройка отключит обязательное подтверждение при работе в собранном EXE
CODE:
options("close", 0);
loop()
{
sleep(1);
}
