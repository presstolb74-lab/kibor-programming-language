Доработана функция format.
Так как в Кибор нельзя напрямую приравнивать char к int и int к char введены функции форматирования.
formatic - возвращает char чисового значения в параметре:
char a = formatic(78);
formatci - возвращает int  char'а значения в параметре:
int a = formatci('b');
