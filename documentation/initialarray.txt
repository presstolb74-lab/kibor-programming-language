НАЗВАНИЕ: initialarray
ИСТОЧНИК: https://kibor-bot.com/forum/topic.php?forum=1&topic=135

initialarray позволяет заполнить массив одинаковыми данными.
Примером служит обнуление массива.
Пример:
CODE:
int a[900];
initialarray(#a[0], 125);
CODE:
new string A [1000000];
initialarray(#A[0], "Wwwww");
Первый параметр указатель на массив, второй - данные которыми заполнится массив.
Допускается указывать начало массива только 0 индекс, то есть заполнять его с начала.
Пример заполнения двухмерного массива. Остальные аналогично.
CODE:
int a[900][20];
initialarray(#a[0][0], 125);
Для char допускается указывать как символ заполнения в 'A', так и числовой код.
CODE:
char a[900];
initialarray(#a[0], 'A');
CODE:
char a[900];
initialarray(#a[0], 65);
Заполнение string
CODE:
string a[900];
initialarray(#a[0], "Бла бла");
CODE:
string a[900];
initialarray(#a[0], "");
Возвращает количество заполненных данных. То есть общий размер массива.
