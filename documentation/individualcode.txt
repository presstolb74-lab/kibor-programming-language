НАЗВАНИЕ: individualcode
ИСТОЧНИК: http://kibor-bot.com/forum/topic.php?forum=1&topic=47

individualcode - возвращает string в котором находится индивидуальный ключ машины на котором запущен. Тот который можно узнать в окне О программе.
Синтаксис
Цитата:
individualcode();
Пример
CODE:
messagebox (individualcode());
Пример как узнать ключ при запуске готового exe
CODE:
CREATE_INTERFACE
{
DIALOG "Название окна" 237 180
BUTTONSCRIPT "Запустить" 125 121 100 25
EDIT_0 "" 105 8 120 18
STATIC_0 "код" 10 10 90 18
}
INITDIALOG
{
sendcontrol(EDIT_0, individualcode());
}
Ссылка для этого примера
Блок кода выполняющийся до создания графической оболочки.
